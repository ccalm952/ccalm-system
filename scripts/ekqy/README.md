# e看牙患者导入

把 e看牙 中某个患者的初诊/复诊病历、治疗计划、复诊关联、收费与收款导入本地开发库。

## 前提

1. 本机 e看牙 浏览器已登录（ego-browser 的 `e看牙导入` 空间）；
2. 本地 API / 数据库可用；
3. `ccalm-api/.env` 里有 `DATABASE_URL`。

## 使用

```powershell
.\scripts\ekqy\import-patient.ps1 "柯文雄"
```

脚本会：

1. 搜索该姓名，取第一条同名患者；
2. 打开电子病历，展开全部病历；
3. 打开收费页，读取收费单与收款；
4. 写入本地库。

## 导入内容

- 患者基本信息（姓名、手机、病历号、性别、生日）
- 每次就诊 `PatientVisit`
- 初诊/复诊 `MedicalRecord`
- 检查、诊断、处置、医嘱、备注
- 初诊治疗计划 `TreatmentPlanItem`
- 复诊与治疗计划的关联 `PlanItemFollowUp`
  - 优先按牙位/文本匹配；
  - 无牙位信息时（如正畸）关联到第一条计划
- 收费：合并成一张初诊治疗收费单，含明细和多笔收款

## 说明

- 同一病历号重复导入时，会先清空该患者已有的病历和收费，再重新写入；
- 就诊记录会复用同日期同时段的已有记录；\n- 同日期已有「待写病历」的就诊（如种植预约生成）会直接复用并补上时间，不再生成重复就诊；
- 牙位使用 e看牙 的 FDI 编码，直接写入本地；
- 治疗计划单价不单独抓取，收费金额以收费单为准；
- 仅供本地开发测试，请确认有权限导出这些患者数据。
